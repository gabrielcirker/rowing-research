# Research website

The public static site is in `docs/`. GitHub Pages should serve `main` / `docs`.

The site presents the current November 2026 report without changing its scientific content. All 12 report pages are rendered inline with text alternatives and an optional native PDF view. The source PDF remains available.

The searchable archive identifies current and historical files, preserves byte-level originals except for the clearly labeled contact-email removal in the JURPA-format PDF, records source-snapshot provenance and SHA-256 checksums, and consolidates exact duplicates. Historical content is not endorsed as validated science. Unrelated third-party material, personal/team records, caches, system metadata, and private working notes are excluded. The unlocated 147-page version is explicitly identified as a coverage limitation.

The original research checkout was not modified by site preparation.
